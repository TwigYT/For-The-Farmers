# For the casual Farmer, Adventurer, and Builder!

Just want a modpack that you can relaxe with? This modpack is for you! The casual player that doesn't want to worry about big storage, big enemies, or complicated systems. 

Here, all you need is in this simple list:
  - New Structures (Abridged, Dungeons and Taverns)
  - Farming (Farmer's Delight, plus addons!)
  - New Biomes (Biomes O' Plenty, Incendium Legacy)
  - LOTS of New Furniture (Every mod from Macaw plus Biomes O' Plenty compatibility, Beautify: Refabricated)
  - LOTS of New Blocks (More Chests Variants, Rechiseled, Stoneworks)
  - Many other mods.

Overall, this pack adds over 11,000 new blocks and items! But don't worry, most of those are different variations of vanilla blocks from Rechiseled and Stoneworks! Giving you more options for making an amazing build.
